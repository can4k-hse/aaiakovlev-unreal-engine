# Домашнее задание 2. Behavior Trees и PCG.

PCG расставляет препятствия на уровне. Охранник патрулирует площадку и обходит кубы. Если видит игрока, начинает погоню.

В дереве поведения два своих узла. **GuardAwarenessService** отвечает за зрение и слух. **FindSearchPoint** выбирает точки поиска рядом с местом, где охранник в последний раз видел или слышал игрока. Через 7 секунд без новых подсказок охранник возвращается к патрулю.

Чтобы проверить слух, пробегите с зажатым **Shift** за спиной охранника в пределах 15 метров. Он пойдёт на звук шагов.
