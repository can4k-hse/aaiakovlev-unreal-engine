# Домашнее задание 2. BT и PCG.

PCG расставляет препятствия (кубики) на уровне. Охранник патрулирует площадку, обходит кубики. Если он видит игрока, начинается погоня.

В дереве поведения охранника два своих узла. **GuardAwarenessService** отвечает за зрение и слух. **FindSearchPoint** выбирает точки поиска рядом с местом, где охранник в последний раз видел или слышал игрока. Через 7 секунд без новых подсказок охранник возвращается к патрулю.

Чтобы проверить слух, пробегите с зажатым **Shift** за спиной охранника в пределах 15 метров. Он пойдёт на звук шагов.

Ожидаемая оценка - 10.
